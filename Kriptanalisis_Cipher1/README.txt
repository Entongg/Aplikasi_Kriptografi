KRIPTANALISIS KELOMPOK 1 - CIPHER1.TXT

Isi folder:
1. cipher1.txt       = cipherteks dari lampiran tugas.
2. analisis.py       = program analisis frekuensi dan pola kata.
3. analisis.txt      = hasil analisis dari analisis.py.
4. deskripsi.py      = program dekripsi (sesuai nama yang diminta).
5. dekripsi.py       = salinan dengan ejaan "dekripsi" yang benar.
6. hasil_dekripsi.txt= hasil dekripsi cipher1.txt.

CARA MENJALANKAN

1. Pastikan Python sudah terpasang.
2. Buka folder ini di VS Code.
3. Buka terminal pada folder tersebut.
4. Jalankan:
   python analisis.py
5. Hasil analisis akan tersimpan otomatis pada:
   analisis.txt
6. Jalankan:
   python deskripsi.py
7. Hasil plaintext akan tersimpan otomatis pada:
   hasil_dekripsi.txt

KUNCI CIPHER -> PLAIN
abcdefghijklmnopqrstuvwxyz
rmfnyjeqduozspvklwhgtxcabi

Contoh:
mjymuzujuzkd wznsgam -> substitution ciphers
zd mzbnqg -> in simple
usg -> the
qguuga -> letter
